Another optimization technique that has gained popularity in recent years is the Adam optimizer ~\cite{kingma2014adam}The Adam algorithm ~\cite{liu2023improved} differs significantly from the traditional SGD algorithms. Adam (adaptive momentum) algorithm occupies fewer resources and makes the model converge faster~\cite{yaguchi2018adam}, which can accelerate the learning speed and improve the effect. It applies the best of both worlds, meaning a combination of two methods ‘RMSProp’ and ‘AdaGrad. 

Adam is a first-order optimization algorithm that can replace the traditional stochastic gradient descent process. It joins the second-moment estimation based on momentum’s first-order moment estimation and adds a moment to the Adadelta. The learning rate of each parameter is dynamically adjusted by using the first and second-moment estimation of the gradient. A bias correction is also added, which makes the parameters relatively stable. The pseudocode~\ref{al2} describes in detail our algorithm.

\begin{algorithm}[H]
\caption{Adam Algorithm Implementation.}\label{al2}
\begin{algorithmic}[1]
\Require Learning rate $\alpha$, num\_iterations
\Require Exponential decay rates $\beta_1$ and $\beta_2$ for moments $v_t$ and $a_t$ respectively.
\Require Small constant $\delta$, for numerical stability
\State Initialize parameter $\theta$, first and second moments $v_t = 0$ and $a_t = 0$.
\State Time step $t = 0$
\For{$i$ in range(num\_iterations)}
    \State Sample $m$ training examples $x_i$ with corresponding labels $\mathrm{first\_y}_i$, $\mathrm{second\_y}_i$
    \State Compute gradients: $g \leftarrow \frac{1}{m} \nabla_\theta \sum_{i=1}^m J(\theta; x_i, \mathrm{first\_y}_i, \mathrm{second\_y}_i)$
    \State $t \leftarrow t + 1$
    \State \textbf{First moment:} $v_t = \beta_1 v_{t-1} + (1 - \beta_1) g$
    \State \textbf{Second moment:} $a_t = \beta_2 a_{t-1} + (1 - \beta_2) g \odot g$
    \State \textbf{Bias correction first moment estimate:} $\hat{v_t} = \frac{v_t}{1 - \beta_1^t}$
    \State \textbf{Bias correction second moment estimate:} $\hat{a_t} = \frac{a_t}{1 - \beta_2^t}$
    \State \textbf{Compute parameter update:} $\Delta \theta = -\alpha \frac{\hat{v_t}}{\sqrt{\hat{a_t}} + \delta}$
    \State \textbf{Update parameters:} $\theta \leftarrow \theta + \Delta \theta$
\EndFor
\end{algorithmic}
\end{algorithm}
